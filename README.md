# Мой-портал.ру — прототип

Статический многостраничный прототип молодёжного портала Тюмени.
Без сборки: чистый HTML + один общий CSS + ванильный JS.

## Запуск

```bash
python serve.py 5500
# http://127.0.0.1:5500
```

`serve.py` отдаёт `404.html` на несуществующие адреса и запрещает кеширование.

## Структура

```
index.html          главная — единственный HTML в корне
404.html            страница ошибки
serve.py            локальный сервер

work/   study/   afisha/   psy/   opp/   feed/
    index.html              страница раздела
    <подраздел>/index.html  страница подраздела (start, resume, admission…)

article/  event/  service/  page/     шаблоны, данные из ?id=/?s=/?p=
podcasts/  services/                   подкасты и каталог сервисов

assets/
  css/style.css      база: токены, сетка, компоненты
  css/sections.css   акценты разделов, блоки, карта, форум, мобильные
  css/motion.css     анимации, рельс, бегущая строка
  js/data.js         разделы и материалы
  js/data2.js        события, сервисы, страницы
  js/blocks.js       тексты подразделов
  js/dates.js        актуальные даты событий
  js/render.js       рендер раздела, материала, подраздела
  js/render2.js      рендер события, сервиса, страницы, поиск
  js/afisha.js       афиша: карточки, календарь, карта, подборки
  js/ui.js           карусель, подписка, авторизация, «наверх», меню
  js/forum.js        комментарии, реакции, почта под аккаунтом
  js/podcasts.js     модальный плеер подкастов
  js/quiz.js         тест профориентации
  js/app.js          тема, меню, поиск, фильтры, ревилы
  js/motion.js       рельс, появление, бегущая строка
  brand/  fonts/  img/  img/team/
docs/                рекомендации (docx/pdf — полная и краткая версии)
screens/             скриншоты для презентации
```

## Правила

- В корне только `index.html`; любая другая страница — папка со своим `index.html`.
- Глубина 1 (`work/index.html`) — `<base href="../">`, глубина 2 (`work/start/index.html`) — `../../`.
  Все внутренние ссылки пишутся от корня: `work/index.html`, `article/index.html?id=…`.
- Акцент раздела задаётся атрибутом `<body data-accent="work|study|afisha|psy|opp|feed">`
  и красит кнопки, свечение, метки и подчёркивание меню.
- Оранжевый `#FF4416` — только на главной.
- Данные не дублируются в разметке: карточки, события, подборки и счётчики считаются из `MP.*`.
- Числа на сайте демонстрационные.

## Что работает в прототипе

Разделы и подразделы · афиша с календарём, картой и подборками · подкасты с плеером ·
тест профориентации · поиск · авторизация (localStorage) · комментарии и реакции ·
персонализация подписки · тёмная тема · адаптив до 390 px.

Ограничение: пользовательские данные хранятся в браузере. Для общего форума нужен бэкенд
(`users`, `posts`, `comments`, `reactions`).
