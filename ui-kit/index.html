Основной

Горизонтальный: «Мой портал» + сигнальная точка. Точка — не украшение, а «вход»: она есть только в логотипе.

Плашка

Квадратная версия для аватарок, мерча и наклеек. Наследует исторический знак портала.

Охранное поле

Свободное поле вокруг знака — не меньше высоты буквы «М». Минимум 96 px по ширине.

08

Фотография

Что снимаем

Людей в их среде: на работе, на событии, в мастерской. Естественный свет, живые эмоции, горизонтальный кроп 16:9 для героя и 4:5 для соцсетей.

Чего не делаем

Стоки с «улыбающимися офисами», коллажи из трёх шрифтов, стоковые градиенты, чужие фото без прав. Мемы — можно, но с указанием источника.

Текст на фото

Только поверх затемнения или на плотной подложке-плашке. Контраст текста к фону — не ниже 4,5:1. Проверяем на телефоне при ярком свете.

09

Анимация

  • 01Только то, что помогает понять: появление блоков, зум фото на 4%, смена состояния кнопки. Ничего «для красоты».
  • 02Длительность 150–300 мс, кривая ease-out. Переход дольше 400 мс ощущается как тормоз.
  • 03При prefers-reduced-motion всё выключается — контент остаётся доступным без движения.
